## 🌟 Project highlights

✅ **HUSTOJ core functions retained**  
- Support C/C++/Python code submission and problem solving  
- Competition/homework management backend  

✅ **PHP+SQL deep optimization**  
- Remove redundant dependencies, **single file deployment**  
- Database query efficiency increased by 30% (tested)  

✅ **Friendly educational environment**  
- Built in **Elementary school friendly question bank** (selected introductory questions from Luogu) (not yet available)  
- Support teachers to import questions with one click (in `.zip` format) (not yet available)  

✅ **Developer friendly**  
- Completely open source, code annotation rate of 90%+  
- Provide secondary development [guide](https://github.com/AccppK/AKOJ/blob/main/docs/hustoj.md)  

✅ **Online demonstration**
